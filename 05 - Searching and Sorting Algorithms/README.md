# 5. Algoritmos de busca e ordenação (Searching and Sorting Algorithms)

## 5.1 Algoritmos de busca (Searching Algorithms)
- Busca linear (Linear Search)
  - Funcionamento
  - Complexidade
- Busca binária (Binary Search)
  - Pré-requisito: vetor ordenado
  - Implementação iterativa e recursiva
  - Complexidade O(log n)

## 5.2 Algoritmos de ordenação (Sorting Algorithms)

### Simples (O(n²)) (Simple Sorting Algorithms)
- Bubble Sort
- Selection Sort
- Insertion Sort

Para cada um:
- Funcionamento passo a passo
- Complexidade
- Estabilidade

### Eficientes (O(n log n)) (Efficient Sorting Algorithms)
- Merge Sort
  - Divisão e conquista
  - Uso de memória extra
- Quick Sort
  - Particionamento
  - Escolha de pivô
  - Pior caso
- Heap Sort
  - Heap binário
  - Construção do heap

## 5.3 Comparações importantes (Important Comparisons)
- Estáveis vs instáveis
- In-place vs não in-place
- Complexidade média vs pior caso
